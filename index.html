04 · The core pattern

Write Python.
Give it a front door.

A simple Python function can become an interactive experience. The book builds your understanding around this core connection between Python logic and the user interface.

app.py
import gradio as gr

def greet(name):
    return f"Hello, {name}!"

demo = gr.Interface(
    fn=greet,
    inputs="text",
    outputs="text"
)

demo.launch()
