# How to Use Gradio with Python: A Complete Beginner-to-Advanced Book

An interactive, animated promotional website for **How to Use Gradio with Python: A Complete Beginner-to-Advanced Book** by **Eva J Patel**.

The website is designed to showcase the book, introduce its learning path, highlight topics covered throughout the book, and direct visitors to the full freeCodeCamp publication.

## ✨ Features

* Gradio-inspired orange and Python-inspired blue/yellow visual theme
* Animated futuristic background and visual effects
* Animated book mockup
* Smooth navigation between sections
* Scroll-based reveal animations
* Interactive hover effects
* Interactive code showcase
* Book chapter and learning-path sections
* Author section featuring Eva J Patel
* Direct link to the full freeCodeCamp book
* GitHub profile link
* Responsive layout for different screen sizes
* Entire website contained in a single HTML file

## 📚 About the Book

**How to Use Gradio with Python: A Complete Beginner-to-Advanced Book** teaches readers how to use Gradio to turn Python functions, machine learning models, data-processing workflows, and AI applications into interactive web interfaces.

The book progresses from basic Gradio concepts to complete AI-powered applications, covering topics such as:

* Gradio fundamentals
* Components and inputs/outputs
* Events and interactivity
* Layouts and UI design
* State management
* File processing
* Images, audio, and video
* Chatbots
* Machine learning models
* AI applications
* API keys and secrets
* Hugging Face Spaces
* Deployment
* Performance and security
* Production considerations
* A complete AI-powered capstone application

## 🚀 Running Locally

Because this is a single HTML file, you can run it without installing dependencies.

1. Clone or download this repository.
2. Open the HTML file in a modern web browser.
3. Explore the website.

For GitHub Pages, the main HTML file should be named:

`index.html`
